🔴 PROBLEM

Users are prematurely logged out after 10 minutes of activity due to a mismatch in JWT token expiration evaluation. [Issue #247]

💡 WHY / ROOT CAUSE

Commit [commit a83f21] reduced the JWT expiration token threshold from 30 minutes to 10 minutes without updating the corresponding refresh token grace period logic in the API middleware.

🕐 HISTORY & CONTEXT

The project originally used a 30-minute JWT duration. During a security audit [PR #231], the expiration lifetime was shortened for security compliance, introducing downstream session revocation bugs.
